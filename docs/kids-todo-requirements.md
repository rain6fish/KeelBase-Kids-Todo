# 小计划 — 需求确认书

> 应用：儿童每日学习计划管理（家庭协作）
> 底座：KeelBase v1.3.0（Flutter + NestJS + Taro + Web-Admin-Vue）
> 本文是需求事实源；实现规格见 [kids-todo.spec.md](kids-todo.spec.md)。

## 1. 产品目标

让家长和孩子在同一个家庭空间里安排每日学习任务、记录完成情况、给出反馈，并用积分/徽章形成正向激励。

## 2. 角色

| 角色 | 说明 | 关键权限 |
|------|------|---------|
| 家长（parent） | 家庭创建者或受邀加入的第二位家长 | 创建/编辑任务、审批孩子创建的任务、管理奖励、查看家庭统计、修改家庭设置 |
| 孩子（child） | 家长在家庭内创建，使用登录账号 + PIN 登录 | 查看/完成自己的任务、创建任务（受审批开关约束）、请求帮助、兑换奖励、查看自己的积分与连签 |

约束：

- 一个家庭最多 2 位家长。
- 一个用户只属于一个家庭。
- 孩子账号不绑定邮箱/手机号，邮箱验证视为通过（由家长线下核实身份）。

## 3. 核心流程

### 3.1 家长注册与家庭创建

1. 家长用用户名 + 邮箱 + 密码注册。
2. 系统自动创建一个家庭，注册者成为第一位家长，并获得 8 位家庭邀请码。
3. 第二位家长可用邀请码加入（最多 2 位）。
4. 家长可修改家庭名称、审批模式和可用时段；「删除家庭」只把状态改为 inactive，成员、任务、积分全部保留，可随时恢复。

### 3.2 孩子加入与登录

1. 家长在家庭设置页点击「添加孩子」，填写昵称 + 4-6 位数字 PIN（登录账号可选，不填自动生成）。
2. 孩子在登录页选择「孩子登录」，输入家庭邀请码 + 登录账号 + PIN。
3. 登录成功后进入任务页。

### 3.3 任务

- 家长可直接创建任务并指派给孩子。
- 孩子在家庭开启「审批模式」时创建任务，状态为 `pending`，需家长通过后生效。
- 任务状态：`todo` → `doing` → `done`，或 `cancelled`。
- 完成任务时：加积分、更新连签、写入当日打卡记录；重复任务自动生成下一次实例。
- 孩子可对任务「请求帮助」并附说明。
- 任务页提供月历，点选日期即查询该日任务；任务以儿童友好的彩色卡片展示（大字号、优先级配色）。

### 3.4 任务备注（对话式）

- 家长可在任务详情里写备注/说明，孩子可回复，形成按时间排列的对话气泡。
- 备注只追加不覆盖；每条备注显示作者与时间。
- 任务列表页对存在未读备注的任务显示提示，打开详情后自动已读。
- 任务详情同时展示「操作历史」，默认折叠、点击展开；每条显示谁、在什么时候、做了什么（含状态变化）。历史进入不可删的变更流水。
- 任务、备注、家庭均只做软删除或状态变更，不物理删除，历史与数据可追溯。

### 3.5 奖励

- 家长/孩子可创建奖励（名称、描述、所需积分、是否启用）。
- 孩子兑换奖励时扣减积分并生成兑换记录。
- 兑换可取消，取消后退回积分。

### 3.6 积分、连签与统计

- 每完成一个任务 +10 分。
- 连续有完成记录的日期累加连签；中断则从 1 重新开始。
- 家庭统计：今日完成率、成员数、家庭总积分、最近 N 天每日完成率、孩子创建任务占比。
- 个人统计：总积分、当前/最长连签、最近 30 天打卡记录。

### 3.7 每日评价

家长可对孩子某一天写评价（1-5 星 + 文字），同一孩子同一天同一家长唯一。

### 3.8 离线同步

- 设备登记后，客户端可按家庭拉取增量变更（`GET /sync/changes?since=`）。
- 离线期间的「创建 / 完成 / 删除任务」进入本地队列，恢复后通过 `POST /sync/push` 逐条推送。
- 推送结果逐条返回 `applied / conflict / error`；冲突带回服务端当前版本，客户端下次刷新收敛。

## 4. 验收标准

- [ ] 家长注册后自动拥有家庭与邀请码。
- [ ] 孩子可用邀请码 + 登录账号 + PIN 登录，看不到其他家庭数据。
- [ ] 家长与孩子都能看到同一家庭的任务、备注、奖励、评价。
- [ ] 完成任务后积分 +10、当日打卡记录更新、连签正确。
- [ ] 重复任务完成后生成下一次实例。
- [ ] 审批模式下孩子创建的任务为 `pending`，家长可通过/驳回。
- [ ] 兑换奖励扣分；取消兑换退分。
- [ ] 家庭统计与个人连签数据与任务记录一致。
- [ ] 家长写备注、孩子可回复，对话按时间展示且不覆盖历史。
- [ ] 任务详情展示操作历史；删除任务/备注/家庭后历史记录仍在。
- [ ] 任务页日历选择日期后，仅显示该日任务，卡片适合儿童阅读。
- [ ] App 底部导航恰好 5 个入口（今日/任务/家庭/奖励/我的）。
- [ ] 达到积分/连签阈值时自动授予对应徽章，同一徽章不重复授予。
- [ ] 离线完成/删除任务恢复网络后自动推送，冲突逐条回报。
- [ ] 所有用户可见文案走 i18n（中/英），管理端不出现明文手机号等隐私字段。
- [ ] `node scripts/keelbase-doctor.mjs` PASS；后端构建/单测、Flutter analyze/test、Web 构建、Taro 构建通过。
