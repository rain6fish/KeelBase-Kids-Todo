# 产品需求文档（PRD）：儿童每日学习计划管理应用

> 版本：v1.0 | 日期：2026-11-02 | 作者：产品团队

---

## 一、产品概述

### 1.1 产品定位

一款面向 6-15 岁儿童家庭的「每日学习计划管理工具」，帮助孩子养成自主规划学习的习惯，同时让家长能够适度参与、监督和引导，而非替代孩子做决定。

### 1.2 核心价值

- **对孩子**：学会自己规划每天的学习任务，获得完成任务的成就感
- **对家长**：了解孩子的学习安排，及时引导和激励，两个家长协同参与
- **对家庭**：建立可视化的学习节奏，减少"你今天学了什么"的无效追问

### 1.3 产品形态

- 移动端（iOS / Android），家长端以手机为主
- 网页端（PC / 平板），孩子做作业时用大屏更方便
- 两端数据实时同步

---

## 二、用户角色

| 角色 | 说明 | 权限概要 |
|------|------|----------|
| **孩子** | 计划的主要执行者 | 创建/编辑/完成自己的任务，查看家长备注 |
| **家长 A**（如爸爸） | 监督与引导者 | 创建/编辑/删除所有任务，查看操作流水，写备注 |
| **家长 B**（如妈妈） | 监督与引导者 | 权限同家长 A，与家长 A 平级 |

**关键约束**：
- 一个家庭最多绑定 2 个家长 + 若干孩子（v1.0 先支持 1 个孩子，后续扩展多孩子）
- 每个操作都记录操作人身份（孩子 / 家长A / 家长B），用不同颜色或头像标识
- 家长之间权限平等，但可以设置"审批模式"（可选）：孩子创建的任务需要家长确认后才生效

## 三、功能需求

### 3.1 任务管理模块（核心）

#### 3.1.1 创建任务

- **任务标题**：必填，简短描述（如"完成数学练习册第3单元"）
- **任务分类**：可选标签，如语文、数学、英语、阅读、运动、其他；支持自定义标签
- **计划时间**：可选，设定开始时间和结束时间（如 16:00-17:00）
- **预计时长**：可选，预估完成需要多少分钟
- **优先级**：高 / 中 / 低，用颜色区分（红/黄/绿）
- **重复设置**：可选，设为每日/每周重复（如"每天阅读30分钟"）
- **创建人标识**：系统自动记录，显示"由爸爸添加""由孩子自己添加"

#### 3.1.2 任务状态流转

```
待开始 → 进行中 → 已完成
                  → 已取消
```

- 孩子可以拖拽切换状态（移动端滑动，网页端拖拽）
- 已完成的任务由孩子自己标记，培养自主性
- 家长可以修改任何任务的状态
- 已取消的任务需要填写原因（可选）

#### 3.1.3 编辑与删除

- 创建人可以随时编辑自己的任务
- 家长可以编辑和删除任何人的任务
- 删除操作需要二次确认，且删除后仍保留在操作流水中

#### 3.1.4 任务备注

- 每个任务支持添加多条备注/评论
- 备注支持文字，后续可扩展语音和图片
- 每条备注显示作者和时间
- 备注可用于：家长给提示（"这道题注意单位换算"）、孩子记录困难（"这道题不会，明天问老师"）、家长给评价（"完成得很认真 ⭐"）

---

### 3.2 日程视图模块

#### 3.2.1 日视图（默认）

- 按时间线展示当天所有任务
- 未设置时间的任务排在"灵活任务"区域
- 当前进行中的任务高亮显示
- 顶部显示完成进度条（已完成/总任务数）

#### 3.2.2 周视图

- 以周为单位展示任务分布
- 帮助家长和孩子回顾一周的学习节奏
- 可以按天展开查看详情

#### 3.2.3 日历视图（网页端增强）

- 月历形式展示，有任务的日期有标记
- 点击日期跳转到该日的日视图

---

### 3.3 操作流水模块

#### 3.3.1 流水记录内容

每一条操作都记录以下信息：

| 字段 | 说明 |
|------|------|
| 操作时间 | 精确到秒 |
| 操作人 | 孩子 / 家长A / 家长B，显示昵称和头像 |
| 操作类型 | 创建任务 / 编辑任务 / 完成任务 / 取消任务 / 删除任务 / 添加备注 / 修改状态 |
| 操作对象 | 具体哪个任务 |
| 变更内容 | 修改前 → 修改后（如"优先级：中 → 高"） |

#### 3.3.2 流水查看方式

- 全局流水：按时间倒序展示所有操作
- 按任务查看：在任务详情里看该任务的所有操作历史
- 按人筛选：只看某个人的操作
- 按日期筛选：查看某天的操作记录
- 流水记录不可删除、不可篡改（保障监督的透明性）

---

### 3.4 激励与反馈模块（补充建议）

这是你原始需求里没有、但我强烈建议加的部分。孩子坚持用下去的动力不是"被监督"，而是"有成就感"。

#### 3.4.1 积分系统

- 每完成一个任务获得积分（可按优先级设置不同积分：高=3分，中=2分，低=1分）
- 积分可兑换家长预设的奖励（如"积满50分可以看电影""积满100分买一个玩具"）
- 奖励池由家长设置和管理

#### 3.4.2 连续打卡

- 记录连续完成所有任务的天数
- 连续打卡 7 天 / 30 天 / 100 天有成就徽章
- 网页端展示打卡日历，视觉上很有满足感

#### 3.4.3 每日/每周统计

- 今日完成率、本周完成率
- 各学科时间分布（饼图）
- 家长端可看到趋势图：孩子是否在进步

---

### 3.5 通知与提醒模块（补充建议）

#### 3.5.1 任务提醒

- 任务开始前 10 分钟推送提醒（可配置时间）
- 孩子端：App 内通知 + 系统推送
- 家长端：可选接收孩子任务完成情况的通知

#### 3.5.2 超时提醒

- 任务超过预计完成时间未完成，给孩子温和提示（"这个任务花了比预期更长的时间，需要帮忙吗？"）
- 同时通知家长（可选）

#### 3.5.3 家长留言通知

- 家长添加备注时，孩子端收到通知
- 孩子完成任务时，家长端收到通知

---

### 3.6 家庭协作模块（补充建议）

#### 3.6.1 家长之间

- 家长 A 可以看到家长 B 添加/修改了什么
- 支持家长间在任务备注里 @对方（" @妈妈 这道题孩子错了3次"）
- 避免重复布置任务：添加任务时如果标题与今日已有任务相似，给出提示

#### 3.6.2 亲子沟通

- 孩子可以对任务标记"我需要帮助"，家长端收到提醒
- 每日小结：家长可以写一段简短的每日评价（"今天表现很棒，数学进步很大"），孩子能看到

---

### 3.7 账户与安全模块

#### 3.7.1 注册与登录

- 家长通过手机号注册，设置密码
- 创建家庭时生成家庭邀请码
- 第二个家长通过邀请码加入家庭
- 孩子通过家长扫码或输入邀请码加入，孩子账号不需要手机号，降低隐私风险

#### 3.7.2 数据安全

- 儿童数据加密存储，不对外共享
- 符合《儿童个人信息网络保护规定》
- 家长可以导出所有数据，也可以注销账户并删除全部数据

#### 3.7.3 隐私保护

- 孩子端不展示任何社交功能
- 无广告、无外部链接
- 家长可设置"使用时间段"，超出时间孩子端锁定（避免沉迷）

## 四、非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 任务列表加载 < 1秒，操作响应 < 500ms |
| 同步 | 多端数据同步延迟 < 3秒 |
| 可用性 | SLA 99.5%，数据每日备份 |
| 兼容性 | iOS 14+、Android 8+、主流浏览器（Chrome/Safari/Edge 最近两个大版本） |
| 无障碍 | 字体大小可调，支持大字体模式；配色对儿童友好，避免高对比度刺眼 |
| 离线 | 移动端支持离线查看和基础操作，联网后自动同步 |

## 六、端适配策略

| 功能 | 手机端 | 网页端 |
|------|--------|--------|
| 任务列表与状态切换 | ✅ 主要交互场景 | ✅ 支持 |
| 创建/编辑任务 | ✅ 表单适配移动端 | ✅ 更宽敞的编辑体验 |
| 日程视图 | ✅ 日视图为主 | ✅ 日/周/月视图 |
| 操作流水 | ✅ 简化查看 | ✅ 完整查看+筛选导出 |
| 统计报表 | ✅ 简要概览 | ✅ 完整图表 |
| 备注与沟通 | ✅ 即时通知 | ✅ 支持 |
| 奖励管理 | ✅ 家长端 | ✅ 家长端 |

**建议**：手机端侧重"快速操作+通知"，网页端侧重"全局查看+数据分析"。

## 七、MVP 与迭代建议

### Phase 1（MVP，建议 6-8 周）

优先做能跑通核心链路的最小版本：

- 注册/登录/加入家庭
- 创建/编辑/完成/取消任务
- 任务备注
- 操作流水（基础版）
- 日视图
- 创建人标识
- 基础通知

### Phase 2（体验增强，+4-6 周）

- 积分与奖励系统
- 连续打卡与成就徽章
- 周视图/月视图
- 重复任务
- 统计分析
- 离线支持

### Phase 3（生态扩展）

- 多孩子支持
- 语音备注
- 家长每日评价
- 学习报告导出（PDF）
- 与学校日历/作业系统对接（如果可行）

## 八、风险与注意事项

1. **儿童隐私合规**：涉及未成年人数据，需严格遵守《个人信息保护法》和《儿童个人信息网络保护规定》，建议上线前做合规审查。
2. **亲子关系风险**：产品设计要避免变成"家长监控工具"，否则孩子会抵触。核心是"帮助孩子自主管理"，而非"让家长盯着孩子"。建议在文案和交互上多给孩子正向反馈。
3. **家长冲突**：两个家长教育理念不一致时，可能在任务上产生矛盾（爸爸布置的，妈妈删了）。操作流水的透明性可以缓解这个问题，但产品上可以考虑加"家长协商"机制。
4. **留存问题**：工具类产品孩子容易用几天就不想用了。积分、打卡、徽章等游戏化元素不是锦上添花，而是留存的核心手段。
